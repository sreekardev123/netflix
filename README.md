# Netflix Clone - React.js & Tailwind CSS

## 🚀 Overview
This is a **Netflix Clone** built using **React.js** and **Tailwind CSS**. The application provides users with a seamless movie browsing experience, featuring a movie catalog, user authentication, reviews, and a dashboard for managing content.

## 🎬 Features

### ✅ **Movie Browsing & Filtering**
- Display a collection of movies with posters and trailers.
- Filter movies by categories (e.g., Action, Drama, Comedy) using dropdowns.
- Click on a movie image or 'Watch' button to navigate to the watch page.

### ✅ **Movie Watch Page**
- Displays the movie trailer.
- Includes a review section where users can share their thoughts.
- Allows sharing movie trailers with others.

### ✅ **User Authentication (Firebase Auth)**
- Login and Signup functionality.
- Guest login support.
- Firebase authentication for secure access.

### ✅ **Dashboard**
- Displays a list of all movies.
- Allows users to add new movies.
- Manage categories (add/edit/update categories for movies).
- View and manage users.
- Update profile and change password.
- Favorite movies section.

### ✅ **Additional Features**
- **React Toastify** for displaying notifications/messages.
- **Swiper.js** for smooth movie carousel navigation.
- **Responsive Design** for mobile-friendly browsing.

## 🛠️ Tech Stack
- **Frontend:** React.js, Tailwind CSS, Swiper.js
- **Authentication:** Firebase Auth
- **State Management:** React Hooks
- **Notifications:** React Toastify

## 🔧 Installation & Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/netflix-clone.git
   cd netflix-clone
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Create a `.env` file and configure Firebase credentials.

4. Start the development server:
   ```bash
   npm start
   ```
